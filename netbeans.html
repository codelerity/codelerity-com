Codelerity is not currently providing publicly available installer packages for Apache NetBeans.

We can provide bespoke, supported packages for business and education - get in touch.

Codelerity developed the NBPackage tool, and donated it to the ASF. You can use this tool directly to build installers. Our build repository also remains available, and can be forked and used as a template to build installers via GitHub Actions. Please remove references to Codelerity in the configuration before sharing them!

We can also provide support for NetBeans platform developers who wish to use NBPackage to create packages for their application, either locally or via automated build.

Check out PraxisLIVE - our real-time re-codeable framework and IDE.
And keep an eye open for the other exciting things we're working on in the development space.
